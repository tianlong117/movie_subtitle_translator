# 仅翻译字幕模式设计

日期：2026-11-21
状态：已获用户确认

## 目标

允许用户不选择 MKV 电影，只选择一个字幕文件，直接翻译并输出字幕；不封装视频、不调用 ffmpeg，也不修改源字幕。

## 范围

本次只改“仅字幕模式”。原有“MKV 电影 + 内嵌/外挂字幕 → 翻译后封装 MKV”的流程保持不变。

支持的字幕格式：`.srt`、`.ass`、`.ssa`。

不支持：MP4 内嵌字幕（`mov_text`）、PGS 等图形字幕、语音识别、批量翻译。

## 入口与界面

- 未选择电影时，点击现有“选外挂字幕...”按钮，选择 `.srt/.ass/.ssa`，进入仅字幕模式。
- 已选择电影时，点击同一个按钮仍是原行为：把外挂字幕附加到待封装的 MKV。
- 仅字幕模式下：
  - 视频框保持为空。
  - 字幕轨下拉框显示 `外挂字幕：文件名`。
  - 输出框自动填入主输出路径，仍可手动修改。
  - “同时导出翻译后的字幕”复选框禁用，因为输出本身就是字幕。
- 字幕轨行下方始终显示灰色说明文字：
  `未选择视频文件时，仅选择字幕文件即可单独翻译字幕。`
  用于让用户直接发现仅字幕模式。
- 日志框下方居中显示可点击的“版权说明”链接。
- 先选字幕、再选电影时，按现有 `_load_video` 逻辑清空外挂字幕，回到电影模式，并重新启用导出复选框。
- 仅字幕模式下不显示“正在封装 MKV”阶段，取消按钮在翻译全程可用。

## 输出规则

### 后缀按目标语言生成

所有输出文件均使用现有的 `target_suffix` 映射，不固定 `.zh`。例如：

| 目标语言 | 后缀 |
| --- | --- |
| 简体中文 | `.zh` |
| 繁体中文 | `.cht` |
| 英语 | `.en` |
| 日语 | `.ja` |
| 法语 | `.fr` |
| 韩语 | `.ko` |

其余目标语言同理。

### 输出文件数量

主输出格式由源字幕决定：

| 源字幕 | 主输出 | 额外输出 |
| --- | --- | --- |
| `Movie.en.srt` | `Movie.en.<目标后缀>.srt` | 无 |
| `Movie.en.ass` | `Movie.en.<目标后缀>.ass` | `Movie.en.<目标后缀>.srt` |
| `Movie.en.ssa` | `Movie.en.<目标后缀>.ass` | `Movie.en.<目标后缀>.srt` |

- `.ssa` 主输出按现有规则转换为 `.ass`。
- 额外 SRT 与主输出同目录、同基名，扩展名固定为 `.srt`。
- 示例：源 `Movie.en.ass`，目标日语：
  - `Movie.en.ja.ass`
  - `Movie.en.ja.srt`
- 额外 SRT 使用 pysubs2 从同一份翻译结果另存：基础样式（粗体/斜体等）转换为 SRT 标签，复杂 ASS 定位标签丢弃，时间轴和译文不变。

### 输出框行为

- 输出框填写主输出路径。
- 目标语言改变且用户没有手动改过输出框时，自动路径同步更新。
- 用户手动修改输出框后，不再自动覆盖。
- `另存为...` 根据源格式过滤：
  - `.srt` 源：只允许 `.srt` 主输出。
  - `.ass/.ssa` 源：只允许 `.ass` 主输出。
- 额外 SRT 路径由主输出路径自动推导，不接受单独设置。

## 流程

### 开始前校验

仅字幕模式：

1. 已选择字幕文件且文件存在，后缀为 `.srt/.ass/.ssa`。
2. LLM 已配置。
3. 输出路径非空，且主输出扩展名与源格式匹配：
   - 源 `.srt` → 输出必须 `.srt`。
   - 源 `.ass/.ssa` → 输出必须 `.ass`。
4. 输出路径不能与源字幕路径相同，绝不覆盖源文件。
5. 输出目录可写。
6. 主输出或额外 SRT 已存在时，列出所有冲突文件并询问是否覆盖；用户拒绝则不开始。
7. 保存当前源/目标语言配置。

电影模式保持原有校验。

### 仅字幕任务

新增独立的 `_run_subtitle_task`：

1. 读取字幕文件，记录可翻译条数。
2. 创建 `LLMClient` 和 `TranslationJob`，复用现有分批、去重、重试、进度、取消逻辑。
3. 翻译完成后保存主输出。
4. 如果源是 `.ass/.ssa`，再把同一份结果保存为同基名 `.srt`。
5. 删除成功任务的 partial 字幕。
6. 完成消息同时列出主输出和额外 SRT，并提供打开所在文件夹。

partial 字幕使用现有 `make_partial_path` 风格，放在主输出目录；取消或失败时保留并提示路径。partial 只需要主格式，不额外生成 SRT partial。

### 完成与失败

- 主输出保存成功、额外 SRT 保存失败：视为部分成功，提示主输出路径和 SRT 失败原因，不删除已生成的主输出。
- 主输出保存失败：任务失败，保留 partial（如可写）。
- 取消：保留 partial（如可写），提示路径。
- 仅字幕任务不会进入封装阶段，因此不会被封装阶段阻塞取消。

## 代码改动

### `app/gui.py`

新增纯函数（便于测试）：

- `expected_primary_suffix(source: Path) -> str`：`.srt` → `.srt`；`.ass/.ssa` → `.ass`。
- `default_subtitle_output_path(source: Path, target_lang: str) -> Path`：`<源 stem>.<目标后缀><expected_primary_suffix>`。
- `srt_compat_path(primary: Path) -> Path`：主输出同基名 `.srt`。
- `needs_srt_compat(source: Path) -> bool`：源为 `.ass/.ssa` 时为真。

修改：

- 新增 `COPYRIGHT_TEXT` 常量，保存上述版权说明原文。
- `_build_ui`：在“字幕轨”行下方新增灰色说明标签（跨列、左对齐），后续行号顺延；在日志框下方新增居中的“版权说明”链接。
- 新增 `_open_copyright_dialog`：打开只读模态对话框，显示 `COPYRIGHT_TEXT`，提供“关闭”按钮。
- `_choose_external_subtitle`：无电影时进入仅字幕模式，刷新输出框并禁用导出复选框；有电影时保持原逻辑。
- `_set_output_auto` / `_on_target_changed`：支持字幕源自动路径。
- `_choose_output`：按模式过滤字幕/MKV 扩展名。
- `_start`：按“有电影/仅字幕”分流校验，仅字幕模式启动 `_run_subtitle_task`。
- 新增 `_run_subtitle_task`：加载、翻译、保存主输出和额外 SRT，复用现有进度/取消/错误处理。
- `_set_inputs_enabled` 或模式同步方法：仅字幕模式禁用导出复选框，回到电影模式恢复。
- `done` 消息支持多个输出路径；电影模式仍只列 MKV（如勾选导出，可继续按现有日志显示侧车字幕）。

### `tests/test_gui.py`

新增测试：

- SRT 源默认输出：`Movie.en.srt` + 简体中文 → `Movie.en.zh.srt`
- ASS 源默认输出：`Movie.en.ass` + 日语 → `Movie.en.ja.ass`
- SSA 源默认输出：`Movie.en.ssa` + 繁体中文 → `Movie.en.cht.ass`
- 额外 SRT 路径：`Movie.en.ja.ass` → `Movie.en.ja.srt`
- `needs_srt_compat`：SRT 为假，ASS/SSA 为真
- 未知/不支持后缀的行为（校验阶段拒绝）
- `COPYRIGHT_TEXT` 包含开发者、自由软件、不存储/不分发内容、用户自行承担版权责任等关键句
- 手动检查：点击“版权说明”链接弹出对话框，文本可选中复制，点“关闭”正常返回

现有 128 个测试必须保持通过。

## 边界与假设

- 目标语言可与源语言相同；沿用上一轮“源/目标语言表一致”的设计，不做限制。
- 仅字幕模式不读取、不修改电影文件。
- 电影模式的输出命名已经使用目标语言后缀，本次不改电影模式行为，也不在电影模式额外生成 SRT。
- ASS 转 SRT 只保证文本、时间轴和基础样式；复杂定位、绘图、特效会丢失。
- 不做批量队列、拖拽导入、字幕时间轴调整。
